# Gramil marking gauge

[`gramil-assembly.step`](gramil-assembly.step) is Paul Fremantle's
[gramil](https://github.com/pzfreo/gramil) assembly, exported from that repository's build
(`dist/step/gramil_assembly.step`, which is not committed there). The same export is
published in draftwright-rust as
[`tests/fixtures/assembly/gramil.step.gz`](https://github.com/pzfreo/draftwright-rust/blob/v0.2.5/tests/fixtures/assembly/gramil.step.gz)
(see its [provenance note](https://github.com/pzfreo/draftwright-rust/blob/v0.2.5/tests/fixtures/assembly/gramil.md));
this file is that fixture decompressed, unmodified.

SHA-256: `49a5b403a4b2b87d258efa9384fa18b5ef8290be818e2fa09e5922599d26ed4d`.

The gramil v0.2.0 release's `gramel_assembly.step` is an older export without product names,
so it is not used here.
